# Stage 3 Readiness Checklist

**Snapshot date:** 27 November 2026  
**Purpose:** Track finalisation of the AI Overview learning resources against the Stage 3 requirements and teacher feedback.

This checklist is a working control document. A task is complete only when the final file and its evidence have been inspected.

## A. Shared module and source content

- [ ] All eight topics align with the module learning outcomes.
- [ ] Technical terms are explained for beginners and used consistently.
- [ ] Important claims have relevant in-text citations and a complete reference entry.
- [ ] Open peer-review items are resolved or explicitly documented.
- [ ] Relevant diagrams/images are embedded where they support learning, with captions and alternative text.
- [ ] Tables, diagrams, hyperlinks, and references remain readable and functional in exported files.
- [ ] A beginner learner has tested selected explanations and activities.

## B. Study Guide

- [ ] Complete coverage of all eight topics and learning outcomes.
- [ ] Meets the assignment's required length (the working target recorded for this project is at least 90–100 pages; verify the exact rubric wording before export).
- [ ] Clear title page, clickable table of contents, consistent headings, page numbers, glossary, and further-reading links.
- [ ] Beginner-friendly explanations, key terms, worked examples, and useful summaries.
- [ ] Relevant original or properly attributed images/diagrams, including captions and readable labels.
- [ ] Rich activities, including suitable electronic/platform-based activities rather than relying only on paper exercises.
- [ ] Activity instructions identify tools/materials, steps, expected output, and privacy precautions.
- [ ] Exercises appear before their answers; answer explanations are grouped in a separate section.
- [ ] Editable Word master opens correctly; PDF export is checked page by page.

## C. Separate Test Bank

- [ ] Separate editable Word document, not merely questions embedded in the Study Guide.
- [ ] At least 20 true/false questions.
- [ ] At least 20 multiple-choice questions.
- [ ] At least 6 open-ended questions.
- [ ] Questions cover all eight topics and vary in cognitive demand.
- [ ] Every question is self-contained and includes all context needed to answer.
- [ ] Distractors are plausible; only one best answer unless the item explicitly says otherwise.
- [ ] Questions are not accidentally answered by wording or nearby content.
- [ ] Answer key is separate and includes explanations, not only letters/true-false labels.
- [ ] Question-to-topic mapping and total counts are checked.

## D. PowerPoint collection

- [ ] Complete editable slide collection covers all module learning outcomes.
- [ ] Teaching story has a clear opening, learning goals, concept development, examples/demonstrations, audience practice, recap, and next steps.
- [ ] Slides use concise text, meaningful visuals, and a consistent Botol visual identity.
- [ ] Main text is approximately 28–32 pt where practical; crowded slides are split rather than made unreadably small.
- [ ] Visuals are relevant, legible, captioned/attributed where necessary, and not just decorative.
- [ ] Large-class audience activities have clear instructions and expected responses.
- [ ] Presenter notes are included in the editable PPTX.
- [ ] Presentation script and timing are prepared.
- [ ] Live demonstrations have a screenshot/recorded fallback.
- [ ] Rehearsal checks timing, transitions, visibility, and audience participation.

## E. Video tutorials

- [ ] Each video teaches a concept or process rather than simply reading slides aloud.
- [ ] Explanations are paced for beginners and include examples or demonstrations.
- [ ] Narration is clear and consistent in volume.
- [ ] Accurate subtitles/captions are included.
- [ ] On-screen text is readable and visuals are sufficiently clear.
- [ ] Videos have a clear opening, learning goal, explanation/demo, recap, and next step.
- [ ] Final exports meet the assignment's file format, count, and size requirements.
- [ ] Each video has been watched from beginning to end after export.

## F. Cross-resource alignment and submission

- [ ] [Resource mapping](../submission/report/RESOURCE_MAPPING.md) lists actual chapters/pages, question IDs, slide numbers, and video timestamps.
- [ ] Terminology, examples, and learning outcomes are consistent across the Study Guide, Test Bank, PPT, and videos.
- [ ] Teacher feedback action plan is updated with actual revisions and evidence.
- [ ] Final improvement summary identifies what changed, why, and where.
- [ ] Final submission report records the real snapshot date, commit, filenames, links, and team contributions.
- [ ] Final editable files and required exports are included in the correct submission locations.
- [ ] Final ZIP/package is extracted to a separate folder and checked for missing/corrupt files.
