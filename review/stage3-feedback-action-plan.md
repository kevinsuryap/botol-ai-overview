## Verification notes

For each action, record:
1. The exact file changed.
2. The section/page/slide/video timestamp affected.
3. The feedback point addressed.
4. Who checked the change and when.
5. Evidence that the change works for a beginner learner.

Use **Completed** only after the evidence has been inspected. Use **Partly completed** when only some topics or files have been revised.
