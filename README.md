# Botol — AI Overview

A team project for *Foundations of CS & AI* (2026). We are building beginner-friendly learning materials for the **AI Overview** module: a Study Guide, PPT Slides, and Video Tutorials, all based on one shared body of checked Markdown content.

## Purpose

This project helps beginners build a clear first picture of artificial intelligence. After using our materials, a learner should be able to:

- Explain in plain language what AI is, with everyday examples;
- Describe how AI relates to neighbouring ideas such as machine learning;
- [add or adjust goals after the outline is agreed, e.g. explain what an intelligent agent is];
- Recognise that AI systems can make mistakes, and describe one way to check them.

We write and review the explanations, examples, activities, and references in Markdown first. The Study Guide, slides, and videos are then produced from this checked content, so all three teach the same ideas. When an explanation changes, every affected deliverable is updated.

## Intended learners

- **Who:** first-year university students with no technical background in computer science or AI.
- **Assumed knowledge:** everyday computer and internet use only. No programming and no advanced mathematics.
- **Not assumed:** any AI terminology. Each technical term is defined when it first appears.

## How we work

- One branch and one pull request per task. We do not commit directly to `main` after the initial setup.
- Each member commits their own work from their own GitHub account.
- Another member reviews every pull request before it is merged.
- Significant AI assistance is recorded, with how the output was checked.
